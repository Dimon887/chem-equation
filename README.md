Это программа, которая уравнивает химические уравнения реакций.
В ней присутствует одна консольная и две графические версии.
Новейшая на данный момент версия: graphic_.py
В программе используется рекурсивный метод разбора молекулы для преобразования в вид словаря, система уравнений для расстановки и классический графический интерфейс от Tkinter.
Эта программа способна решать абсолютно любые уравнения.
